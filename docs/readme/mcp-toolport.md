# Toolport and automatic MCP registration (Setup version)

- For Claude Code and Codex separately, Setup skips `claude mcp add` / `codex mcp add` when (1) that client's settings contain the Toolport gateway (`mcpServers` in `~/.claude.json`, or `~/.codex/config.toml`), and (2) Toolport's registry has an enabled server that starts an `edictora.exe` with the `mcp` argument, in a profile that is in use. Same file as Setup's: recorded reason `toolport`; a different file: `toolport-foreign`. If this can't be determined, Edictora registers directly.
- The registry is `%APPDATA%\Toolport\registry.json` on Windows (override with `TOOLPORT_REGISTRY` / `TOOLPORT_DATA_DIR`), `~/Library/Application Support/Toolport/registry.json` on macOS, and `$XDG_CONFIG_HOME/Toolport/registry.json` (absolute path only, else `~/.config/Toolport/registry.json`) on Linux. Other OSes aren't checked and register directly.
- An existing registration is never removed. If you later remove the gateway from that client, or the executable Toolport points to is gone, Edictora adds the direct registration at the next update or sign-in. If you disable or delete Edictora in Toolport, it doesn't add one. A client Setup has registered directly once isn't re-added after you remove it; only a skipped client is added back.
- To remove only the direct registration after adding Toolport: `claude mcp remove edictora --scope user` or `codex mcp remove edictora`.
- When Setup starts over (first install, new location, or no saved state) while Toolport serves Edictora, it doesn't call the CLI, so a direct registration pointing to the old executable stays. Remove it with the commands above if unneeded.
- If Toolport serves a different `edictora.exe`, Setup skips direct registration, records `toolport-foreign` and logs a warning to `%LOCALAPPDATA%\Edictora.Data\logs\Edictora_yyyy-MM-dd.log`. To fix it, point the `command` of the `edictora` server in Toolport to the Setup executable. Don't copy the executable elsewhere; a copy isn't updated. This is re-judged at every Setup, update and sign-in.
- Toolport's tool quarantine isn't checked.
- `mcpRegistration` in `%APPDATA%\Edictora\config.json` chooses the behavior: `auto` (default), `direct` (always register directly) or `off` (never register or repair automatically; uninstall still removes Edictora's registrations). The installer reads only the default config path. Other commands report any other value as a config error; the installer treats an invalid value or invalid JSON as `auto` and logs it.
