# 掲載画像の画面操作

概要は [掲載画像](../design/listing-images.md)。

- **スロットの特定**（`selectors::pick_image_slot`）: 各 `input[type=file]` を含む最大の祖先の文字列を、寸法の表記と見出し（「全言語向けアセット」「ローカライズ版アセット」）で 1 つに絞る（アイコンは見出しを持たず `128x128` で選ぶ）。絞れなければ止める。言語が 1 つのアイテムにはローカライズ版のスロットが無い。
- **空のスロット**: 削除後も src が空の `<img>` が残るため、src が空でないものだけ数える。
- **削除**: 画像にマウスを乗せて削除ボタン（aria-label「画像を削除 <alt>」）を押し、確認ダイアログ（「この画像を削除してもよろしいですか？この操作は元に戻せません。」）の文面を確かめて「削除」を押す。文面違い・複数のダイアログなら止める。**画像まわりのクリックはこの 2 つだけで、並べ替えには触れない。**
- **アップロード**: 1 枚ずつ `DOM.setFileInputFiles`。枚数が 1 増え、alt が「スクリーンショット N」に揃い、失敗の表示が無いことを待つ（1 枚 60 秒まで）。
- **push の順序**: テキスト → 書き込み可否 → 全言語向け（アイコン → 小タイル → マーキー → スクリーンショット。差分のあるスロットだけ全入れ替え）→ 書き込み可否 → 保存 → 読み直して照合 → ロケールごとに同様 → 保存したなら最後に全対象スロットを再照合（保存なしなら最初の照合結果を使う）。置換は「末尾から 1 枚ずつ削除 → 正本を先頭から 1 枚ずつアップロード → 枚数照合」。審査待ちなどでは最初の削除の前（`ensure_allowed`）と各保存の直前に止める。
- **ロケール切替の合図**: `switch_locale` は説明欄の値が 2 回続けて同じになるまで待つ。説明が同じ言語同士（Vuora は 7 言語が同じ英語）では切替前の画像を置換しうるため、**ローカライズ版画像の書き込みに限り**「説明欄＋ローカライズ版スロットの src の並び」の指紋が変わること（最大 15 秒）を合図にする。合図が無ければ最初の削除の前に `WriteBlocked`（終了コード 4）、保存後の読み直しではエラー。説明も画像も直前の言語と同じアイテムでは push が止まる（迂回手段なし）。**未確認**: 最後の照合と差分なしの判定は合図を確かめないこと、説明と画像が同時に入れ替わるか、既定の言語にローカライズ版スロットがあるか、テキストの push の同種の隙。
