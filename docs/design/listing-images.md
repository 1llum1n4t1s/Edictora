# 掲載画像

- **対象**: ストア アイコン（128x128、1 枚、全言語共通。画面上の名前は「ショップ アイコン」）・小タイル（440x280）・マーキー（1400x560）・全言語向けスクリーンショット（1280x800 か 640x400、1〜5 枚）・ローカライズ版スクリーンショット（言語ごと、同じ寸法・枚数）。動画・並べ替えは対象外。v1 は PNG だけ（8 ビット・インターレースなし。アイコン以外は 24 ビット・アルファなし。**アイコンだけは RGBA も可**）。アイコンは `--image-scope global` に含め、小タイルより前に処理する。
- **正本の検証**（Chrome を開く前、終了コード 2）: 実在・PNG ヘッダー・ビット深度と色形式・寸法・セット内で画素が重複しない・枚数。画素のダイジェストもここで計算する。
- **比較は画素で行い、比較不能を一致にも置換にもしない。** 2026-11-15 に SearchClock で、サーバーがアップロードを再エンコードして保存し（`=s0` の原本はバイト列もサイズも変わる）、画素は同じことを確かめた。そこで `images/png.rs` でデコードした RGB 画素に幅・高さを前置した SHA-256 で比べる（zlib の展開は自前）。全不透明の RGBA は RGB に落とす。透過・インターレース・8 ビット以外は「比較不能」でそのアイテムを止める（同日のバックアップ 188 枚はすべて比較できた）。
  - **アイコンだけはアルファ込み**（`png::pixel_digest_rgba`。完全に透明な画素は 0 に正規化、RGB は A=255）で比べる。角丸などで透過を持つのが普通のため。選択は `images::digest_for_slot` がスロットごとに行う。
- **現在値の取得**: 段ごとの `<img>` の alt と src を集め、src 末尾のサイズ指定を `=s0` に置き換えて `net/winhttp.rs` で取得する（上限 16 MB、https の `*.googleusercontent.com` だけ、Cookie・リダイレクトなし。Cookie なしで 200 が返ることは実画面で確認済み）。取得できなければ「比較不能」。
- **画面操作**: スロットは寸法と見出しで 1 つに絞り、クリックは削除ボタンと削除確認だけ。差分のあるスロットだけを全入れ替えし、保存後に読み直して照合する。書き込みは日本語の画面だけ。詳細は [掲載画像の画面操作](../agents/image-slot-operations.md)。
