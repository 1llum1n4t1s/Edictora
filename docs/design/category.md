# カテゴリ

- **対象**: 「ストアの掲載情報」タブのカテゴリ（全言語共通の欄。祖先の文字列に「すべての言語用」が別の行で出る）。ロケール単位の `ListingField` には入れず、アイテム直下の `category`（設定）・`ExpectedItem::category`（正本のキー）・`ItemSnapshot::category`（現在値。`Ok` は選ばれている選択肢の `data-value`、`Err` はこの欄だけの読み出し失敗）として別に持つ（`listing/category.rs`）。
- **設定**: 値は言語に依らない小文字のキーで、`data-value` から `CATEGORY_` と `EXTENSIONS_` を除いて小文字にしたもの（`productivity`・`communication`・`tools`・`developer_tools`・`workflow_and_planning`・`education`・`lifestyle`・`art_and_design`・`entertainment`・`games`・`shopping`・`social_networking`・`news_and_weather`・`well_being`・`household`・`travel`・`just_for_fun`・`make_chrome_yours`・`privacy_and_security`・`accessibility`・`functionality_and_ui` の 21 種類）。対応は `listing::category::CATEGORIES` の 1 か所だけに持つ。キーなし＝対象外。未知の値（大文字・`CATEGORY_` つき・プレースホルダー `Select a category`・空文字を含む）は Chrome を開く前に終了コード 2 で、有効なキーを案内する。プレースホルダー（未選択）は正本にできず、選ぶ操作もしない。`locales` を書かず `category` だけのアイテムも許す。
- **DOM と読み出し**: コンボボックスと一覧は閉じたまま、選択肢の `data-value` と `aria-selected` を読む。詳細は [カテゴリ欄の DOM と読み出し](category-dom.md)。
- **書き込み**（`ListingPage::write_category`、**日本語の画面だけ**。`DashboardText::category` が英語は `None` で、英語の画面では書かずに止める）: `selectors::pick_category_combobox`（ラベルの 1 行完全一致）で選んだコンボボックスを実マウスで開く → 一覧の枠に大きさが出るまで上限つき（10 秒）で待つ（`category_list_visible`）→ `pick_category_option` で `data-value` が正本の選択肢をちょうど 1 つ選び（プレースホルダーは選ばない）、実クリック → コンボボックスの `aria-expanded="false"` と、その選択肢の `aria-selected="true"` を上限つき（5 秒）で確かめる。閉じなければ言語切替の前例（`get_locales`）と同じく Escape を送ってもう一度確かめ、それでも満たされなければ止める。
- **手順**（`services::push_core`）: 全言語共通なので、ロケールのループの外で 1 回だけ読む・書く。不足ロケールの確認より後・ロケールのループより前に、独立した 1 サイクル（読む → 差分なら書く → 保存前の照合 → 書き込み可否 → 下書き保存 → 読み込み直し → 照合）で行う。不足ロケールで止まる push はカテゴリも書かない。審査待ちなど書き込み不可なら最初の `ensure_allowed` で何も書かずに止まる。ロケールの保存後の最終の読み直しでも、カテゴリが動いていないかを照合する。ロケールを切り替えても同じ値が読めること（言語切替の影響を受けないこと）は、2026-11-19 に 9 言語アイテムの `push` で確かめた。
- **`pull` / `diff`**: カテゴリの読み出しの失敗はこの欄だけのエラー（失敗時のページのスナップショットを保存）にして、ロケールの読み出しは続ける。`diff` はカテゴリの行を出し（`[カテゴリ] 一致: <キー>` / `差分あり` + `- 現在値 / + 正本`。現在値は対応表のキー、未選択は「（未選択）」、表に無い値は生の値）、差分で終了コード 3、エラー・未取得で 1。`--only text` に含み、`--locale` では絞らない（`--image-scope` とも無関係）。
