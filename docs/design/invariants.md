# 重要な不変条件

- **プロファイルは秘密情報で、ツールは削除しない。** 削除する経路を持たない。終了は `Browser.close`、応答しないときだけプロセスを止める。ログイン待ちの間はタブに接続しない。パスワードと確認コードはツールが扱わない。
- **publisherId はログイン後の URL から実行時に取り出し、コード・設定・ログに書かない。** ログと CLI のエラー出力は伏せ字処理を通す。
- **既定は読み取りのみ。** 書き換えは `push --yes`、審査送信は `submit --item <id> --yes` を明示したときだけ。下書き保存と審査送信は別の操作で、審査送信は 1 件ずつ。「審査の合格後に自動的に公開する」の状態は変えずに報告する。
- **書き込み可否は許可リスト方式**（`write_gate.rs`）。確認済みの状態（公開済み・下書き・拒否）以外、審査待ち・ロック中・判定不能なアイテムには書き込まない。審査の取り消しはしない。
- **保存前と保存後に正本と照合する。** 一致しなければ保存しない・エラーで止める。途中で失敗したら、そのアイテムの残りは行わない。再読込・遷移で beforeunload が出たら、「留まる」を選んで未保存の変更を捨てずに中止する。
- **画像と「プライバシー」タブの書き込みは審査送信に届かない。** 手順は審査送信を持たない trait（`ImagePage`・`PrivacyPage`）だけを受け取る。テストは `submit_for_review` が panic する偽ページで push 全体を通す。画像の手順の規則（クリックの限定・画素比較・削除の即時反映）は [掲載画像](listing-images.md)、権限の欄の不整合で何も書かない規則は [「プライバシー」タブ](privacy-tab.md)。
- **同じプロファイルは 1 件ずつ。** Chrome を開くコマンドは `<profileDir>\edictora-profile.lock` を排他で取り、使用中・開けないなら Chrome を開かず終了コード 1。保存・画像の削除とアップロード・審査送信の直前に、タブが対象アイテムのページのままかを照合し直す。
- **要素の特定が曖昧なら止める。** 候補がちょうど 1 つに絞れなければ、最初の 1 つを選ばず止める（別の欄を書き換える事故を防ぐ）。
- **Chrome を前面に出さない。** `Page.bringToFront` は使わず、操作の前に毎回 `Emulation.setFocusEmulationEnabled` を行う。
- **引数と設定の誤りは Chrome を開く前に終了コード 2 で止める。**
- **失敗時の診断はページのテキスト スナップショット**（`%LOCALAPPDATA%\Edictora.Data\diagnostics`、リポジトリの外）で、スクリーンショット（画像）は撮らない（AI が画像を見ずにテキストで原因を読めるようにするため）。ファイル名は `yyyyMMdd-HHmmss-<ラベル>.txt`。以前の `.png` は自動では消さない。
  - 中身（ページ内スクリプトの `snapshot()`）: 先頭に URL・タイトル・`<html lang>`・ビューポート・`readyState`、続けて見えている要素を字下げのツリーで `<役割> "<名前>" value="<値>" {<状態>...} @x,y,w,h` の 1 行ずつ。役割は `role` 属性か主要タグの暗黙の役割で、意味の無い入れ子の div / span は子へ畳み、素の文字列は `text "..."` で出す。display:none・visibility:hidden は部分木ごと省き、0x0 の要素は自分の行だけ省いて子へ降りる（閉じた一覧の `option` と `input[type=file]` は `{hidden}` 印つきで残す）。textarea・select は子をたどらず値だけ出し、iframe の行にも矩形を付ける。open な shadowRoot と同一オリジンの iframe はたどる。パスワード欄の値は文字数も出さず `(masked)` だけ。途中で例外が出ても、それまでの行に `... (snapshot error: ...)` を足して必ず文字列を返す。1 値 2,000 文字、全体 1,000,000 文字で切る。
  - 保存前に `logging::redact_diagnostics`（`devconsole/` の直後と publisherId の文字列そのものを `<publisher>` にする）と `logging::redact_account`（アカウント ボタンの名前「Google アカウント: <氏名> (<メール>)」の氏名を `<name>`、メールアドレスの形を `<email>` にする。実画面で確認済み）を通す。
- **検証していないパッケージは適用しない。** サイズとハッシュがフィードと一致したものだけを Update.exe に渡す。
